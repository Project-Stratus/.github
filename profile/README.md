# 🎈 Project Stratus

**A student-led project at Imperial College London, affiliated with the Imperial College Space Society.**

We're building an amateur-scale, high-altitude, station-keeping balloon platform for weather monitoring, stratospheric imagery and experiments, plus a reinforcement learning (RL) agent that flies it autonomously.

## What we're working on

- **Station-keeping RL agent:** an agent that controls a balloon's altitude to ride wind currents and hold position around a target location.
- **Balloon hardware and payload:** Arduino controller, onboard sensors (humidity, temperature, wind speed, UV and more), a camera, and a valve and ballast system for altitude control (in development).
- **Ground station and telemetry:** GPS tracking and radio communications.

## Get involved

We're open to new members, whether you're into ML, electronics, software, atmospheric science, or just want to launch something into the stratosphere. No experience needed, just a desire to build cool things :)
